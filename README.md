# HR Analytics Dashboard 

An automated HR business intelligence solution built using **Looker Studio**. This project transforms raw workforce metrics into interactive, actionable dashboards to help HR leaders optimize hiring, improve employee retention, and track organizational health.

## 📊 Live Dashboard Link
[👉 Click here to view the interactive Report](https://datastudio.google.com/reporting/a4e53580-022b-4cbc-a278-4841bde9cc38)
## 🎯 Key Features & Views
* **Recruitment Funnel:** Tracks time-to-hire, cost-per-hire, and offer acceptance rates across various sourcing channels.
* **Attrition & Retention Tracker:** Identifies turnover trends by department, tenure, and role type to highlight flight risks.
* **DEI Scorecard:** Monitors demographic distribution, gender representation, and pay equity markers across leadership levels.
* **Workforce ROI:** Displays headcounts, revenue per employee, and training program completion metrics.

## 🔌 Data Architecture & Tech Stack
* **Visualization:** Looker Studio
* **Data Sources:** Google Sheets / BigQuery (Simulated HRIS and ATS data exports)
* **Data Fields Included:** Employee ID, Department, Hire Date, Termination Date, Salary, Performance Rating, Sourcing Channel.

## 🚀 How to Replicate This Project
1. **Prepare the Data:** Review the sample schema provided in the `/data` folder of this repository.
2. **Connect to Looker Studio:** Create a new data source in Looker Studio and select the Google Sheets / CSV connector.
3. **Apply the Theme:** Set up the report layout using the custom corporate styling templates documented in the repository.
